## 📊 数据分析项目
本文件夹收录基于 Python 爬虫工具完成的量化分析，涵盖宏观经济、公司金融、消费市场等领域。

| 项目名称 | 数据类型 | 研究方向 | 核心内容简介 |
|---------|---------|---------|-------------|
| 2025-2026上证指数变化分析 | 上证指数日度时间序列 | 宏观经济 / 金融市场 | 分析指数波动趋势、关键事件影响与收益率特征，可视化市场情绪与宏观经济联动 |
| 一致魔芋财务分析报告 | 公司财务报表 | 公司金融 / 财务分析 | 多维度评估偿债、盈利、营运能力，揭示经营风险与投资价值 |
| 我国宠物经济现状及未来研究方向 | 上市公司年报 / 行业面板 | 消费经济学 / 产业研究 | 基于A股宠物经济公司数据，挖掘行业驱动因素、竞争格局与发展趋势 |
